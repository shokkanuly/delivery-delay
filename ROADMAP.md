# SitePulse — current roadmap

Start with one construction site and a supplier history audit. The build plan with acceptance
criteria is [docs/plans/mvp-reshape.md](docs/plans/mvp-reshape.md); earlier platform work is in
[the historical build log](docs/archive/build-roadmap.md).

| Status | Scope |
|---|---|
| Implemented | 1C CSV import and quality report; supplier/material scorecards; chronological audit; tenge exposure. |
| Implemented, engineering primitives | Fixed-time equipment solver, phase checks, signed gate intake and prediction/outcome evidence loop. |
| Next engineering work | Database migrations, then roles and human slot approval; daily at-risk view and outbox. New dependencies require founder approval. |
| Before customer intake | Separate Kazakhstan/on-prem deployment, backup/restore test, access/retention agreement and a named site owner. |
| Next commercial evidence | Document interviews, run one authorised real audit, agree one 30-day pilot and measure adoption/arrival coverage. |
| Later, after evidence | Several sites, named users and shared tenancy only when actual customer needs justify them. |

Judge preparation improves access to the working prototype and the quality of evidence. It does
not count as a customer pilot or complete pending product stages. See [judge guide](docs/JUDGES.md).
